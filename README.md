# Maze Game with Rain Effect

This project is a maze game that uses raycasting techniques to render the environment in 3D. Additionally, a rain effect has been added to enhance the visual experience.

## Requirements

- SDL2
- SDL2_image
- GCC (or any compatible C compiler)

## Installation

1. Clone the repository:
    ```bash
    git@github.com:JerryEnClavE/maze.git
    cd maze.git
    ```

2. Install the necessary dependencies:
    ```bash
    sudo apt-get install libsdl2-dev libsdl2-image-dev
    ```

3. Compile the project:
    ```bash
    make
    ```

## Usage

To run the game, simply execute the generated binary:
